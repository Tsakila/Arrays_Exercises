# Arrays with Loops in VB.NET

A Practical Guide to Array Manipulation Using Loops

This repository contains 8 exercises demonstrating how to work with arrays and loops in VB.NET.

Each exercise focuses on a different operation, from basic iteration to advanced transformations.


![Exercises UI](https://github.com/user-attachments/assets/528e81f7-7559-4e78-ba3d-4f2a96b1669c)

📌 Exercises Overview
1. Display Each Item in a Separate MessageBox
   
🔹 Loop through an array and show each element in individual message boxes.

2. Display All Items in a Single MessageBox
   
🔹 Combine all array elements into a single string (with newlines) and display them together.

3. Calculate and Display the Sum of All Items
   
🔹 Add all array values and show the total in a message box.

4. Calculate and Display the Average of All Items
   
🔹 Compute the average value of the array and display it.

5. Sum Values Greater Than 20
    
🔹 Only add numbers larger than 20 and output the result.

6. Find the Largest Value in the Array
    
🔹 Determine the maximum value and display it.

7. Find the Smallest Value in the Array
   
🔹 Determine the minimum value and display it.

8. Double Each Value & Output the New Array
    
🔹 Multiply every element by 2 and show the updated array.



📥 How to Use

Clone/download the repository. [https://github.com/Tsakila/Arrays_Exercises.git]

Open in Visual Studio. [Download using this link : https://visualstudio.microsoft.com/downloads/]

Run each exercise individually to see the output.



🎯 Key Learnings

✔ Looping through arrays (For, For Each)

✔ Mathematical operations on arrays (Sum, Average, Min, Max)

✔ Conditional filtering (e.g., values > 20)

✔ Modifying array values (e.g., doubling each element)
